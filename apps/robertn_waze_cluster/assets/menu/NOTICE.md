# Temporary menu vehicle artwork

`m3-reference.png` was generated with the built-in image-generation tool on
2026-11-08. It is a generic blue-violet BMW M3 G80 illustration, following the
user's request to use the reference car temporarily before an X4 M-specific
version. It is not a photograph of the user's car or a BMW-supplied asset.

Prompt: One blue-violet BMW M3 G80 sedan, front three-quarter view facing left,
complete car visible, black double kidney grille, black multi-spoke wheels,
realistic proportions, crisp studio CGI product rendering similar to a premium
in-car 3D vehicle menu. Transparent alpha, no ground plane, a subtle tight tire
shadow, no labels, UI, watermark or other objects. Soft controlled studio
reflections and clear edges against dark navy.

The application embeds a losslessly compressed 800 x 400 RGBA derivative in
`src/cockpit_car.js`. Vehicle settings and ownership labels remain X4 M.
